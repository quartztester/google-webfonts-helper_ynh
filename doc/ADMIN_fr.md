Pour passer l'application du mode démo à la liste complète de polices, ouvrez le panneau de configuration de l'application dans l'interface d'administration et collez une clé gratuite « Web Fonts Developer API » (créée sur <https://console.cloud.google.com/apis/library/webfonts.googleapis.com>) dans le champ Clé d'API Google Fonts. Le service redémarre automatiquement.

La clé se trouve dans `__INSTALL_DIR__/.env`, le cache des archives de polices dans le dossier de données de l'application. Les journaux sont dans `/var/log/__APP__/__APP__.log`.
