Google Webfonts Helper permet de télécharger les fichiers de polices Google (eot, ttf, svg, woff, woff2) et les extraits CSS `@font-face` correspondants, afin d'héberger les polices sur votre propre serveur au lieu de pointer vers celui de Google.

La liste des polices est récupérée via l'API Google Web Fonts Developer, qui nécessite une clé d'API gratuite : sans clé, l'application fonctionne en mode démo avec 3 polices d'exemple.
